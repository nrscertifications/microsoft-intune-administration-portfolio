# Screenshot Publishing Notes

The evidence documents non-production Microsoft lab administration. Screenshots are organized by technical workstream and phase rather than course section.

## Kept Visible

- Lab account identifiers and tenant domains
- Device, server, group, policy, and project names
- OS versions, membership rules, configuration choices, and status values
- Useful warnings, intermediate states, and troubleshooting results
- Existing annotations that identify the relevant controls

## Privacy and Credential Handling

- The personal email address in the Windows Settings sidebar is covered in six registration screenshots.
- Authentication, Wi-Fi, local administrator, and package-protection passwords were already masked in the captured screens.
- The bulk-token success message is visible; no token value is published.
- Provisioning packages, customization files, keys, or live credential files are not included in this repository.

## Evidence Selection and Preservation

The archive contains 73 unique lab screenshots. Selected images are embedded near the technical explanation; the rest remain available through the evidence index.

The original 79-image upload is preserved separately. Five Apple certificate demonstration images with instructor/course identifiers are retained in that original backup and are not presented as my lab administration. One byte-identical GPO screenshot is represented once in the published archive.

Screenshot dimensions and technical content are preserved. Only the specified personal-email redaction boxes change pixels in the published copies.
